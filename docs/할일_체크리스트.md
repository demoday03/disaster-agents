# 직접 해야 할 일 (2026-11-20 기준)

코드로 할 수 없어서 사람이 직접 해야 하는 일이다. 끝난 항목은 `[ ]`를 `[x]`로 바꾼다.
비밀값(토큰·비밀번호)은 Render·Turso 화면에만 넣고 채팅이나 저장소에 적지 않는다.

먼저 **1번(마이크로비트 올리기)과 2번(토큰 넣기)**을 하면 실제 센서 시연을 바로 맞춰 볼 수 있다.

## 1. 센서 연결 (하드웨어)

구조: 노드 A → 무선(radio, 그룹 23) → G 마이크로비트 → USB 케이블 → 노트북 게이트웨이 → 서버.
블루투스 모듈은 쓰지 않는다.

- [ ] **노드 A**: MakeCode(https://makecode.microbit.org) → JavaScript 탭에 `microbit/makecode/A_침수.ts` 붙여 넣고 받아서 올리기
  - 수위 310 미만 초록(P5), 310~320 노랑(P8), 320 초과 빨강(P9) + 펌프 켜짐(릴레이 P2)
- [ ] **G**: `microbit/makecode/G_게이트웨이.ts`를 같은 방법으로 올리기 → 노트북에 **데이터용 USB 케이블**로 연결 → 화면에 `U` → 하트가 뜨면 정상
  - `microbit/makecode/hex/` 파일은 예전 버전이라 쓰지 않는다
- [ ] **노드 A 전원**: 펌프·릴레이가 있으니 확장보드에 보조배터리로 따로 전원 넣기
- [ ] **실제 물에서 확인**
  - [ ] 310 / 320 기준이 맞는지(B 버튼 = 지금 수위 값 표시)
  - [ ] 값이 흔들리면 `A_침수.ts` 맨 위에 `led.enable(false)` 넣고 다시 재기(P4는 화면과 같이 쓰는 핀)
  - [ ] 빨간불일 때 펌프가 **켜지는지**(반대로 동작하면 릴레이 방향 문제)
  - 기준을 바꾸면 `A_침수.ts`의 `CAUTION`·`DANGER`와 `config/monitor.json`의 `A.depth`를 같이 바꾼다
- [ ] (선택) 방수 온도센서(DS18B20): 쓸 거면 데이터선(노랑)과 3V 사이에 4.7kΩ 저항. 안 쓸 거면 발표에서 빼기

## 2. 센서 값을 사이트로 보내기

- [ ] 노트북에서 `pip install pyserial`
- [ ] `python gateway/microbit_gateway.py --new-token`으로 토큰 만들기
- [ ] 그 토큰을 **Render → Environment → `SENSOR_GATEWAY_TOKEN`**에 직접 넣기(채팅·저장소에 적지 않기)
- [ ] 노트북 PowerShell에서 실행
  ```
  python gateway/microbit_gateway.py --list-ports
  $env:SENSOR_GATEWAY_TOKEN="토큰"
  python gateway/microbit_gateway.py --server https://disaster-agents.onrender.com --port COM번호
  ```
- [ ] 담당자 화면 **센서·안내문 검증** 탭에 값이 들어오는지 확인
