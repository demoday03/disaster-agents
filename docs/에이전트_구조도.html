①감시

센서 값으로 위험 단계 후보를 만든다

센서수위 2개가 함께 넘거나, 기울기+진동이 함께 반응
규칙연속 N회여야 '확정 후보', 하나만 반응하면 보류
규칙신고 대조: 신고의 심각도를 같은 곳 센서와 비교(참고용)
✔ 위기 단계 확정은 담당자 승인

②접수

신고 글을 읽고 정리해 상황판에 올린다

AI유형·위치·인원·취약 여부 추출
규칙긴급도 1~4는 규칙이 정함(글 속 지시로 못 바꿈), 같은 사건 묶기
연결급한 신고 → ④ · 물품 → ⑧ · 일손 → ⑥ · 안부 → ③
✔ 담당자가 분류 수정·오접수 처리

③안내·안부

가구 맞춤 안내문, 안전 확인과 무응답 격상

AI표준 행동요령 문장을 가구에 맞게 다듬기 → ⑦ 검증
규칙응답 시간 지나면 취약 가구부터 격상
✔ 안내문 게시·안부 확인 시작 승인

④배치

공공 인력·대피소를 추천한다

규칙제약(통제 구간·수용량) → 점수 가중합 → 1순위+대안 2
AI추천 근거 문장만(선택)
✔ 배치 승인·거절(거절하면 다시 추천)

⑤복구·지원

지원제도 찾기, 피해 신고서 초안, 복구 단계

AI서류에서 필드 추출(업스테이지 문서 파싱)
규칙지원 항목 매칭(정답표), 안내는 ⑦ 검증
✔ 제출·확정은 사람

⑥봉사

복구 요청을 작업으로 나누고 봉사자를 추천

AI요청 글을 작업 단위로 나누기
규칙할 수 있는 일·거리·장비·시간 매칭, 안전 규칙
✔ 봉사자 투입 승인

⑦검증

AI가 쓴 안내가 근거 문서와 맞는지 확인

규칙근거에 없는 숫자는 바로 차단
AI다른 판정 모델이 맞음·틀림·불확실
✔ 불확실하면 담당자 확인, 틀리면 표준 원문

⑧물품

급한 물품 요청을 정리하고 공급원을 추천

AI자유 메모에서 품목 찾기, 부족 안내 초안 → ⑦
규칙긴급도·공급원 점수, 의약품은 자동 매칭 금지
✔ 검토·출고(배치) 승인 뒤에만 재고 감소
